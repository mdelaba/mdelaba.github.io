gdrive-mcp: Privacy Policy

Last updated: 8 November 2026.

gdrive-mcp is a private tool used only by its developer, so that software the developer runs on their own computers and servers can work with the developer's own Google Drive (for example, daily backups of personal project data). This policy describes what the app does with Google user data.

Data the app accesses

The app uses two Google permissions, each for the developer's own account only:

  • https://www.googleapis.com/auth/drive.file: used by scheduled backup jobs. It lets the job create files in Google Drive and read or change only the files it created. It cannot see any other file or folder.
  • https://www.googleapis.com/auth/drive: used by a personal MCP server for Google Drive. It lets the developer's AI assistants, when the developer asks, search, read, create and edit files in the developer's own Drive.

The app does not request access to email, contacts, calendar or profile information.

How the data is used

The backup jobs upload data files from the developer's own server to a Drive folder. The MCP server acts only on the developer's own requests. When the developer asks an AI assistant to read a file, the file's contents are given to that assistant for that request. The app does not use Drive data for anything else, and does not use it for advertising or to train AI models.

Storage and sharing

The app's access tokens are stored on the developer's own private computers and servers and nowhere else. The app does not collect, sell or share Google user data with anyone other than the developer's own AI assistant as described above, and there are no analytics or advertising in the app. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Files stay in the Drive until the Drive's owner deletes them. Access can be revoked at any time at myaccount.google.com/permissions, after which the app can no longer reach the Drive. If the app ever asks for a different permission, this policy will be updated first.
