gdrive-mcp

gdrive-mcp is a small private tool for one person: its developer. It lets software the developer runs on their own computers and servers (an MCP server for Google Drive and scheduled backup jobs) work with the developer's own Google Drive.

What it does

  • Creates and updates files in the developer's own Google Drive, for example daily backups of personal project data.
  • Asks Google for only the drive.file permission, so it can see and change only the files it created itself. It cannot read any other file in the Drive.

The app is not offered to the public and has no sign-up. Its only user is the developer.
