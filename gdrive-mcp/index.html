gdrive-mcp

gdrive-mcp is a small private tool for one person: its developer. It lets software the developer runs on their own computers and servers work with the developer's own Google Drive: a personal MCP server for Google Drive, used by the developer's own AI assistants, and scheduled backup jobs.

What it does

  • Backup jobs use only the drive.file permission: they can see and change only the files they created themselves.
  • The personal MCP server uses the drive permission, so that when the developer asks, an AI assistant can search, read, create and edit files in the developer's own Drive.

The app is not offered to the public and has no sign-up. Its only user is the developer, and it only ever accesses the developer's own Drive.
