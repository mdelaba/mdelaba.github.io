TFW Backup

TFW Backup is a small private tool for one person: its developer. It copies the data files of a personal hobby project, Trading Floor World, to the developer's own Google Drive once a day.

What it does

  • Uploads daily data snapshots (Parquet and JSON files) into a folder named "TFW Backup" in the developer's own Google Drive.
  • Asks Google for only the drive.file permission, so it can see and change only the files it created itself. It cannot read any other file in the Drive.
  • Never deletes anything.

The app is not offered to the public and has no sign-up. Its single user is the developer.
