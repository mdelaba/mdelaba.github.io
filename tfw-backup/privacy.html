TFW Backup: Privacy Policy

Last updated: 8 November 2026.

TFW Backup is a private tool used only by its developer, to back up the developer's own project data to the developer's own Google Drive. This policy describes what the app does with Google user data.

Data the app accesses

The app requests one Google permission, https://www.googleapis.com/auth/drive.file. With it, the app can create files in Google Drive and read or change only the files it created. It cannot see any other file or folder in the Drive. The app does not request access to email, contacts, calendar or profile information.

How the data is used

The app uploads data files from the developer's own server to a Drive folder named "TFW Backup". It uses the permission for that purpose only.

Storage and sharing

The app's access token is stored on the developer's own private server and nowhere else. The app does not collect, sell, share or transfer Google user data to anyone, and there are no third-party servers, analytics or advertising in the app. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Backup files stay in the Drive until the Drive's owner deletes them. Access can be revoked at any time at myaccount.google.com/permissions, after which the app can no longer reach the Drive.
